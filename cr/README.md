# Change Request Records

GitHub pull requests are the preferred change request (CR) medium. This
directory stores equivalent CR records for off-platform review or archival.

Copy `cr/TEMPLATE.md` to a numbered `cr/CR-XXXX-<slug>.md` file. Every record
must identify its base and head/range and include all required sections. A CR
integrated into `main` through the local equivalent flow must have a matching
`Head or Range` entry.
